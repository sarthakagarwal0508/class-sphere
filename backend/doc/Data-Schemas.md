# ClassSphere Data Schemas

This reference summarizes the Mongoose schemas in the latest available backend ZIP plus the classroom schema changes discussed in chat. IDs are MongoDB ObjectIds; timestamps are generated by Mongoose where enabled.

## User

| Field | Type / rules | Notes |
|---|---|---|
| `name` | String, required, 2–80 chars | Trimmed |
| `email` | String, required, unique, max 254 | Lowercase and trimmed |
| `password` | String, optional for Google-only users, `select: false` | bcrypt hash, not raw password |
| `googleId` | String, unique sparse, `select: false` | Google identity subject |
| `role` | `student` or `teacher`, required, default `student` | No admin role |
| `isEmailVerified` | Boolean, default false | Google sign-in verifies email after Google token verification |
| `emailVerificationOtpHash` | String, hidden by default | Never return OTP hash |
| `emailVerificationOtpExpires` | Date, hidden by default | OTP expiry |
| `emailVerificationAttempts` | Number, default 0, hidden | Attempt counter |
| `otpResendAvailableAt` | Date, hidden | Resend cooldown |
| `refreshTokenHash` | String, hidden | Stores hash of current refresh token |
| `createdAt`, `updatedAt` | Date | Mongoose timestamps |

## Classroom (updated)

| Field | Type / rules | Notes |
|---|---|---|
| `name` | String, required, 3–100 chars | Classroom name |
| `description` | String, max 500, default empty | Optional description |
| `subject` | String, trim, max 100, default empty | **Added in recent change** |
| `semesterSection` | String, trim, max 50, default empty | **Added in recent change** |
| `classCode` | String, required, unique, uppercase, trimmed | New code generator produces 6 uppercase hexadecimal characters |
| `teacher` | User ObjectId, required | Classroom owner |
| `students` | Array of User ObjectIds | Enrolled students |
| `createdAt`, `updatedAt` | Date | Mongoose timestamps |

The model/schema file must include `subject` and `semesterSection` before the API can reliably persist these fields. Existing classroom documents may not have them; MongoDB does not automatically rewrite old documents when a schema is changed.

## Assignment

- `title`: required string, 3–150 characters.
- `description`: string, max 5000, default empty.
- `classroom`: required Classroom ObjectId.
- `teacher`: required User ObjectId.
- `dueDate`: required Date.
- `maxMarks`: required number, min 1.
- timestamps.

## Submission

- `assignment`: required Assignment ObjectId.
- `student`: required User ObjectId.
- `answerText`: string, max 10000, default empty.
- `submissionUrl`: string, max 2048, default empty.
- `submittedAt`: Date, default now.
- `status`: `submitted` or `graded`, default `submitted`.
- `marksObtained`: number min 0 or null.
- `feedback`: string max 3000, default empty.
- `gradedAt`: Date or null.
- Unique compound index `{ assignment: 1, student: 1 }`.

## StudyMaterial

- `title`: required string, 3–150 characters.
- `description`: string, max 2000, default empty.
- `classroom`: required Classroom ObjectId.
- `uploadedBy`: required User ObjectId.
- `cloudinaryPublicId`: required unique string.
- `originalName`: required string.
- `fileSize`: required number.
- `mimeType`: string, default `application/pdf`.
- timestamps.

## Announcement

- `title`: required string, 3–150 characters.
- `content`: required string, 3–5000 characters.
- `classroom`: required Classroom ObjectId.
- `teacher`: required User ObjectId.
- timestamps.

## Notification

- `recipient`: required User ObjectId.
- `classroom`: required Classroom ObjectId.
- `announcement`: required Announcement ObjectId.
- `title`: required string, max 150.
- `message`: required string, max 300.
- `isRead`: boolean, default false.
- timestamps.

## Relationships

- A classroom has one teacher and zero or more student members.
- Assignments belong to a classroom and teacher.
- A submission belongs to one assignment and one student; unique per pair.
- Study materials belong to a classroom and uploader and reference a private Cloudinary object.
- Announcements belong to a classroom and teacher.
- Notifications belong to a recipient, classroom and announcement.
- Deleting a classroom must account for dependent submissions/assignments, announcements/notifications, material database rows and Cloudinary files. The cleanup code described in the change log is not transactional across MongoDB and Cloudinary.
